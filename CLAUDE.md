# Project instructions

## Website / frontend design workflow (always use)

For any website, landing page, UI, or frontend design work in this repo, use this four-part setup:

1. **Taste Skill** (`design-taste-frontend`, from Leonxlnx/taste-skill): design references, layout, palettes, copy, and its finish gate. Load it before building or redesigning a page.
2. **Impeccable** (`impeccable`, from pbakaus/impeccable) plus **Emil Kowalski's skills** (`emil-design-eng`, `animation-vocabulary`, `animate`, `review-animations`, `improve-animations`, `choreograph`, `gestures`, `animation-performance`, etc.): the design vocabulary for spacing, type, hierarchy, motion and interaction. Use `impeccable` to critique, audit and polish. Use Emil's skills for motion and interaction details.
3. **Figma MCP**: when a Figma link or file is provided, work from it (`figma:figma-design-to-code` before `get_design_context`).
4. **Playwright** (pre-installed with Chromium): run the site, screenshot it at desktop, tablet and mobile widths, inspect the screenshots, test interactions, and iterate until it looks right. Never call a page done without looking at it rendered.

Skills live in `.claude/skills/`. Third-party skills keep their original licenses (see each folder).
